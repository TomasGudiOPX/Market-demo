# Architecture Snapshot

- Documentation ownership is defined by `AGENT.md`.
- `docs/` owns project-facing docs.
- `openspec/specs/` owns accepted behavior.
- `docs/obsidian-vault/` owns requirement traceability, decisions, and AI evidence.
- `.project-knowledge/accepted/` stores reviewed facts consumed as evidence, not edited by this skill.
